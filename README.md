# 📚 Student Study Tracker

A simple web application to manage study tasks and track progress.

## ✨ Features

- Add study tasks
- Mark tasks as completed
- Track your study progress
- Simple and clean interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Purpose

This project was created to practice web development and JavaScript basics.

## 🚀 Future Improvements

- Add study timer
- Add progress charts
- Save tasks using local storage
- Add dark mode
